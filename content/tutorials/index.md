# Build an agent that does a real job

Each tutorial builds one task-specific agent to a working run. You write the tools, Agentware runs the agent loop on an OpenAI-compatible model, and you need a model API key.

Start with the Hacker News research agent. It reads today's top stories and answers questions about them.

Then [add permissions and audit](/tutorials/add-permissions-and-audit): read the audit record the agent already prints, then move the allow and deny decisions from your code to Kei policies, so an admin manages the rules. The offline run needs no Kei account.

New to Agentware? Read [Build on Agentware](/agentware/build/overview) first, and [install Haikei Skills](/skills/) so your coding assistant can help with each step.
