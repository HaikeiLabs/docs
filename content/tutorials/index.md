# Build an agent that does a real job

Each tutorial builds one task-specific agent from an empty folder to a working run. You write the tools, Agentware runs the agent loop on an OpenAI-compatible model, and you need a model API key, not a Kei account.

Start with the Hacker News research agent. It reads today's top stories and answers questions about them.

New to Agentware? Read [Build on Agentware](/agentware/build/overview) first, and [install Haikei Skills](/skills/) so your coding assistant can help with each step.
