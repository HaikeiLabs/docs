# Next steps

After the initial web onboarding, use these checks before enabling a workflow for a wider team:

1. Confirm the right workspace is selected.
2. Invite only the users who need access and assign appropriate roles.
3. Register only the connectors required for the workflow.
4. Review group membership and policy scope, including any required approvals.
5. Connect the existing harness through agentware to your tenant-side connector runtime.
6. Verify an allowed operation and a denied operation, then review the audit record.

Use the [public Kei skills](https://github.com/HaikeiLabs/skills#installing) with an agent when you want help with repeatable setup. See [CLI authentication and runtime setup](/docs/getting-started/cli-and-runtime) for the administrator CLI. To integrate an agent through the SDK, follow [Build on the Agentware SDK](https://github.com/HaikeiLabs/agentware/tree/main/docs/getting-started). To run Open WebUI governed by Kei, follow [Open WebUI with Kei](/docs/connect-your-harness/openwebui).
