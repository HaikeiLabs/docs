Kei helps a team set clear access rules for its agents and connectors. Start by choosing a workspace, then connect the systems your workflow needs and define who can use them.

## A simple path

1. Create or choose a workspace for the workflow.
2. Register the connector or tools the workflow needs.
3. Write a policy for the people or agents who should use them.
4. Test an allowed action and one that should be denied.

An agent uses Kei through an integration and the runtime in your environment. Installing a skill can guide setup, but it does not grant access by itself.
