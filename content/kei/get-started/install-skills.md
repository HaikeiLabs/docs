# Install Kei skills in your agent

Install the public Kei skills in the agent you plan to use. Skills give an agent reusable instructions for Kei setup; they do not install a runtime or grant access.

Follow the installation instructions in the [Kei skills repository](https://github.com/HaikeiLabs/skills#installing) for your agent. The skills support Claude Code, Codex, OpenCode, Pi, and other compatible agents. Restart or reload the agent if its instructions do not update.

## Check it worked

Ask your agent to list the Kei skills it can use. Continue with [Connect this machine](/content/kei/get-started/connect-this-machine.html) to install the runtime tools and connect a runtime installation.
